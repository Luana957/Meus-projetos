 # 📦 Sistema de Gestão de Estoque

Este é o meu primeiro projeto **Full Stack** desenvolvido durante meus estudos de Análise e Desenvolvimento de Sistemas. O objetivo é gerenciar produtos de forma simples e eficiente.

## 🚀 Tecnologias Utilizadas
* **Front-end:** HTML5 e CSS3
* **Back-end:** Node.js com o framework Express
* **Versionamento:** Git e GitHub

## 🛠️ Como rodar o projeto
1. Clone o repositório
2. Entre na pasta: `cd projeto-Estoque`
3. Instale as dependências: `npm install`
4. Inicie o servidor: `node app.js`
5. Acesse: `http://localhost:3000` no seu navegador.
